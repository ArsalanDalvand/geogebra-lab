# Cylinder Command

#### `Cylinder( <Circle>, <Height> )`
  Creates a cylinder with given base and given height.
#### `Cylinder( <Point>, <Point>, <Radius> )`
  Creates a cylinder with given radius and with given points as the centers of the top and bottom.
