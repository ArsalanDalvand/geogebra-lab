# TurtleRight Command

#### `TurtleRight( <Turtle>, <Angle> )`
  The turtle turns to the right by a given angle.

> [!EXAMPLE]
> `TurtleRight(turtle, 1)` turns the turtle to the right by 1 rad, if  _Pause_ button is displayed. Otherwise you must press the  _Play_ button so that the rotation is effected.

> [!NOTE]
> If you enter `TurtleRight(turtle, 1°)` the turtle turns to the right by 1 degree.

> [!NOTE]
> See also [Turtle](Turtle.md), [TurtleBack](TurtleBack.md),
> [TurtleForward](TurtleForward.md) and [TurtleLeft](TurtleLeft.md) commands.
