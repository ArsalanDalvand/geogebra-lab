# ComplexRoot Command

#### `ComplexRoot( <Polynomial> )`
  Finds the complex roots of a given polynomial in _x_. Points are created in  [Graphics View](Graphics_View.md).

> [!EXAMPLE]
> `ComplexRoot(x^2 + 4)` yields _(0 + 2 ί)_ and _(0 - 2 ί)_

## CAS Syntax

#### `ComplexRoot( <Polynomial> )`
  Finds the complex roots of a given polynomial in _x_.

> [!EXAMPLE]
> `ComplexRoot(x^2 + 4)` yields _{- 2 ί, 2 ί}_

> [!NOTE]
> Use [CSolve Command](CSolve.md) instead.
