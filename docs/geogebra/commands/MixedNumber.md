# MixedNumber Command

## CAS Syntax

#### `MixedNumber( <Number> )`
  Converts the given number to a mixed number.

> [!EXAMPLE]
> * `MixedNumber(3.5)` yields stem:[3 + \frac{1}{2}].
> * `MixedNumber(12 / 3)` yields _4_.
> * `MixedNumber(12 / 14)` yields stem:[\frac{6}{7}].

> [!NOTE]
> See also [Rationalize Command](Rationalize.md).
