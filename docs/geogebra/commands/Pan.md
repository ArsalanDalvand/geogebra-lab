# Pan Command

#### `Pan( <x>, <y> )`
  Shifts the active view by _x_ pixels to the right and _y_ pixels upwards.
#### `Pan( <x>, <y>, <z> )`
  Shifts the active view by (_x_, _y_, _z_) pixels if it is a 3D View, or by (_x_, _y_) pixels if it is 2D View

> [!NOTE]
> * If multiple [Graphics Views](Graphics_View.md) are visible, the command is applied to the active one.
> * See also [ZoomIn](ZoomIn.md), [ZoomOut](ZoomOut.md),
> [SetActiveView](SetActiveView.md) commands.
