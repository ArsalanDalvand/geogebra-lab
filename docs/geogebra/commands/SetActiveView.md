# SetActiveView Command

#### `SetActiveView( <View> )`
  Makes given [View](Graphics_View.md) active.

* 1 or "G" for  _Graphics View_ 
* 2 or "D" for  _Graphics View_ 2
* -1 or "T" for  _3D Graphics View_
* "A" for  _Algebra View_
* "S" for  _Spreadsheet View_
* "C" for  _CAS View_

> [!NOTE]
> * See also [ZoomIn](ZoomIn.md), [ZoomOut](ZoomOut.md), [Pan](Pan.md),
> [SetPerspective](SetPerspective.md) commands.
