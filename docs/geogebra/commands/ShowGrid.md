# ShowGrid Command

#### `ShowGrid( )`
  Shows the grid in the active View.
#### `ShowGrid( <Boolean> )`
  Shows/hides the grid in the active View.

> [!EXAMPLE]
> * `ShowGrid(true)` shows the grid in the active View.
> * `ShowGrid(false)` hides the grid in the active View.

#### `ShowGrid( <View>, <Boolean> )`
  Shows/hides the grid in the  _Graphics
  View_ specified by the number 1 or 2 (or 3 for  _3D View_).

> [!EXAMPLE]
> * `ShowGrid(1, true)` shows the grid in  _Graphics View_.
> * `ShowGrid(2, false)` hides the grid in  _Graphics 2 View_.

> [!NOTE]
> See also [ShowAxes command](ShowAxes.md).
