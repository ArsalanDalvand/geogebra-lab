# RootList Command

#### `RootList( <List> )`
  Converts a given list of numbers {a<sub>1</sub>,a<sub>2</sub>,...,a<sub>n</sub>} to a list of points {(a<sub>1</sub>,0),(a<sub>2</sub>,0),...,(a<sub>n</sub>,0)}, which is
  also displayed in the 
  [Graphics View](Graphics_View.md).

> [!EXAMPLE]
> Command `RootList({3, 4, 5, 2, 1, 3})` returns the list of points _list1={(3,0), (4,0), (5,0), (2,0), (1,0),
> (3,0)}_
