# SetFixed Command

#### `SetFixed( <Object>, <true | false> )`
  Makes the object [fixed](Object_Properties.md) (for true) or not fixed (for false).
#### `SetFixed( <Object>, <true | false>, <true | false> )`
  Makes the object [fixed](Object_Properties.md) (for true) or not fixed (for false) and the second parameter
  determines "Selection Allowed"
