# SelectedIndex Command

#### `SelectedIndex( <List> )`
  Returns the index of the selected element of a [drop-down list](Action_Objects.md).

> [!NOTE]
> See also [SelectedElement](SelectedElement.md) command

> [!NOTE]
> #### `SetValue( <[drop-down list](Action_Objects.md)>, <Number n > )`
>   Set _n_ as [.mw-selflink .selflink]#the index of the selected element# in the drop-down list.
