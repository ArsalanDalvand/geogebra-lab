# Sphere Command

#### `Sphere( <Point>, <Radius> )`
  Creates a sphere with center and radius.
#### `Sphere( <Point>, <Point> )`
  Creates a sphere with center in the first point through the second point.

> [!EXAMPLE]
> `Sphere((0, 0, 0), (1, 1, 1))` yields _x² + y² + z² = 3_
