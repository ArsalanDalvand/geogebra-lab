# RandomPoisson Command

#### `RandomPoisson( <Mean> )`
  Generates a random number from a Poisson distribution with given mean.

> [!EXAMPLE]
> `RandomPoisson(3)` yields a random value from a Poisson distribution with a mean of _3_.

> [!NOTE]
> See also [SetSeed command](SetSeed.md), [RandomBetween command](RandomBetween.md),
> [RandomElement command](RandomElement.md), [RandomBinomial command](RandomBinomial.md),
> [RandomNormal command](RandomNormal.md), [RandomUniform command](RandomUniform.md).
