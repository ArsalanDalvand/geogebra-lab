# SetSeed Command

#### `SetSeed( <Integer> )`
  Seeds the random number generator so that subsequent random numbers will be determined by the seed.

> [!EXAMPLE]
> `SetSeed(33)`

> [!NOTE]
> See also [RandomBetween command](RandomBetween.md), [RandomElement
> command](RandomElement.md), [RandomBinomial command](RandomBinomial.md), [RandomNormal
> command](RandomNormal.md), [RandomPoisson command](RandomPoisson.md), [RandomUniform
> command](RandomUniform.md).
