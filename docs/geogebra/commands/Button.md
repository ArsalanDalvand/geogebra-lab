# Button Command

#### `Button( )`
  Creates a new [button](Action_Objects.md).

#### `Button( <Caption> )`
  Creates a new [button](Action_Objects.md) with given [caption](Labels_and_Captions.md).

> [!EXAMPLE]
> `Button("Ok")` creates a button in the left upper corner of the  [Graphics View](Graphics_View.md) with the caption _Ok_.
