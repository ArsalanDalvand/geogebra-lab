# TurtleForward Command

#### `TurtleForward( <Turtle>, <Distance> )`
  The turtle moves forward with given distance.

> [!EXAMPLE]
> If the turtle is at the origin of the coordinates and the 
> _Pause_ button is displayed the command `TurtleForward(turtle, 2)` moves the turtle to the point (2, 0). Otherwise
> you must press the  _Play_ button so that the displacement is
> effected.

> [!NOTE]
> See also [Turtle](Turtle.md), [TurtleBack](TurtleBack.md),
> [TurtleLeft](TurtleLeft.md) and [TurtleRight](TurtleRight.md) commands.
