# SampleSDY Command

#### `SampleSDY( <List of Points> )`
  Returns the https://en.wikipedia.org/wiki/Standard_deviation#Estimation[sample standard deviation] of the _y_-coordinates of the [points](Points_and_Vectors.md) in the given [list](Lists.md).

> [!EXAMPLE]
> `SampleSDY({(2, 3), (1, 5), (3, 6), (4, 2), (1, 1), (2, 5)})` yields _a = 1.97_.
