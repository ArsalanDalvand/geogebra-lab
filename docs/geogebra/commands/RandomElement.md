# RandomElement Command

#### `RandomElement( <List> )`
  Returns randomly chosen element from the [list](Lists.md) (with uniform probability). All elements in the list
  must be of the same type.

> [!EXAMPLE]
> `RandomElement({3, 2, -4, 7})` yields one of _{-4, 2, 3, 7}_.

> [!NOTE]
> * Hint:* In the  [CAS View](CAS_View.md) this command also works with symbolic input.

> [!EXAMPLE]
> `RandomElement({a,b,c,d})` yields one of _{a, b, c, d}_.

> [!NOTE]
> See also [Element Command](Element.md), [SetSeed Command](SetSeed.md),
> [RandomBetween Command](RandomBetween.md), [RandomBinomial Command](RandomBinomial.md),
> [RandomNormal Command](RandomNormal.md), [RandomPoisson Command](RandomPoisson.md) and
> [RandomUniform Command](RandomUniform.md).
