# SetTrace Command

#### `SetTrace( <Object>, <true | false> )`
  Turns [Tracing](Tracing.md) on/off for the specified object.

> [!EXAMPLE]
> Create a point A, then type in `SetTrace(A,true)`. Select the [Move Tool](Move.md) and drag the point, to show its trace.

> [!NOTE]
> Use [ZoomIn(1)](ZoomIn.md) to clear all traces.
