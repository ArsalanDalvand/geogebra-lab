# AxisStepY Command

#### `AxisStepY( )`
  Returns the current step width for the _y_‐axis.

> [!NOTE]
> * See also [AxisStepX](AxisStepX.md) command.
> * Together with the [Corner](Corner.md) and [Sequence](Sequence.md) commands, the
> AxisStepX and AxisStepY commands allow you to create custom axes (also see section
> [Customizing Coordinate Axes and Grid](Customizing_the_Graphics_View.md)).
